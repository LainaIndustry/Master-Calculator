# CalcVerse — Free Online Calculators & Tools

A production-ready, static multi-tool website built with HTML5, CSS3, and vanilla JavaScript. No backend, no build step, no dependencies.

## Features

- **25+ working calculators** across 7 categories
- **Site-wide search** using local data (no server)
- **Full blog** with 20+ educational articles
- **Complete legal pages** (Privacy, Terms, Disclaimer, Cookie)
- **SEO-optimized**: unique titles, meta descriptions, Open Graph, JSON-LD, canonical URLs
- **AdSense-ready** placeholders (no publisher IDs included)
- **Fully responsive**: mobile, tablet, desktop
- **Accessible**: semantic HTML, ARIA, keyboard navigation, skip links
- **Zero external dependencies** — pure HTML/CSS/JS## Project Structure
