About Developer Tools

These tools handle the small but frequent tasks that come up during development: generating a strong password, encoding a string for a URL, converting between numeric bases, or decoding a Base64 token.

What You'll Find Here

  • Password Generator: cryptographically secure passwords using the Web Crypto API.
  • Base64 Encoder/Decoder: text ↔ Base64 with UTF-8 support.
  • URL Encoder/Decoder: percent-encoding for query strings and paths.
  • Binary Converter: text ↔ binary (8-bit UTF-8).
  • Hex Converter: text ↔ hexadecimal.

Security

All tools run entirely in your browser. No inputs, outputs, or generated passwords are transmitted to any server. This means:

  • Nothing appears in server logs.
  • No third party can see what you encode or generate.
  • You can use these tools even offline after the page loads.

Cryptographic Randomness

The password generator uses crypto.getRandomValues() — the browser's cryptographically secure pseudorandom number generator. This is the same primitive used by password managers and secure systems. We also apply rejection sampling to avoid modulo bias.
