What Is Hexadecimal?

Hexadecimal (base 16) uses 16 symbols: 0–9 and A–F. Each hex digit represents 4 bits, so two hex digits represent exactly 1 byte (8 bits). This makes hex convenient for representing binary data compactly.

How to Use It

  1. Paste text or hex bytes into the input.
  2. Click Text → Hex or Hex → Text.
  3. Copy the result.

Example

The ASCII text Hello encodes to hex bytes: 48 65 6c 6c 6f.

Each pair corresponds to one byte:
H = 0x48
e = 0x65
l = 0x6c
l = 0x6c
o = 0x6f

UTF-8 Encoding

Non-ASCII characters become multiple bytes. For example, "é" is 2 bytes (C3 A9) and "😀" is 4 bytes (F0 9F 98 80). This tool uses UTF-8, matching modern web standards.

Common Uses

  • Debugging: Inspecting raw bytes in network traffic or files.
  • Cryptography: Displaying keys, hashes, and ciphertext.
  • Colors in web design: Hex color codes like #FF5733.
  • Memory addresses: Pointers and offsets are shown in hex.

Common Mistakes

  • Forgetting that hex byte strings must have even length (each byte = 2 hex digits).
  • Confusing hex color codes (#RRGGBB) with arbitrary hex bytes.
  • Using ASCII assumptions for UTF-8 text — non-ASCII characters use multiple bytes.
