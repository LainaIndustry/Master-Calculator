URL Encoder / Decoder

Percent-encode text for safe use in URLs, or decode percent-encoded strings back to readable text. Runs entirely in your browser.

Why URL Encode?

URLs can only contain a limited set of characters. Characters like spaces, &, ?, #, =, and non-ASCII letters must be percent-encoded (e.g. space becomes %20) so they aren't misinterpreted as part of the URL structure.

How to Use It

  1. Paste your text into the input.
  2. Click Encode to percent-encode, or Decode to reverse it.
  3. Copy the result.

Worked Example

Text: Hello World & Friends

Encoded: Hello%20World%20%26%20Friends

encodeURIComponent vs encodeURI

This tool uses encodeURIComponent, which encodes everything except unreserved characters. It's the right choice for encoding query string values or path components. encodeURI leaves URL structure characters (:, /, ?, #, etc.) intact — useful for encoding a complete URL while keeping its structure.

Common Mistakes

  • Encoding a full URL with encodeURIComponent — this breaks the URL by encoding its / and ?.
  • Double-encoding (encoding an already-encoded string).
  • Forgetting that "+" in a query string often means a space in form data, but not in path segments.
