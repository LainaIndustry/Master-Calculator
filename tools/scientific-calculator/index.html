What Is a Scientific Calculator?

A scientific calculator handles more than the four basic operations. It supports trigonometry (sin, cos, tan), logarithms (log, ln), powers, roots, and mathematical constants like π and e.

How to Use It

  1. Click the on-screen buttons, or type directly using your keyboard.
  2. Use parentheses for grouping.
  3. Press = (or Enter) to evaluate.
  4. Use C to clear or ⌫ to delete the last character.

Radian vs Degree Mode

This calculator uses radians for trig functions (standard for scientific work). To convert degrees to radians, multiply by π/180. For example, sin(30°) = sin(π/6) ≈ 0.5.

Example Calculations

  • 2 + 3 × 4 = 14 (multiplication before addition)
  • (2 + 3) × 4 = 20 (parentheses change precedence)
  • √(16) + 2^3 = 4 + 8 = 12
  • log(1000) + ln(e) = 3 + 1 = 4

Common Mistakes

  • Forgetting operator precedence — use parentheses when in doubt.
  • Mixing radians and degrees.
  • Dividing by zero (shows "Error").
  • Entering multiple decimal points in one number.
