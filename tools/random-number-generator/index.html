What Is a Random Number Generator?

It produces unpredictable integers within a range. Unlike pseudo-random algorithms seeded from the clock, this tool uses the Web Crypto API — the same primitive used in cryptography — for true unpredictability.

How to Use It

  1. Set the minimum and maximum values.
  2. Choose how many numbers to generate (1–1000).
  3. Optionally enable "unique" to avoid duplicates.
  4. Click Generate.

What "Secure" Randomness Means

Math.random() is fine for games but predictable — given enough outputs, an attacker can infer future values. crypto.getRandomValues() is seeded from system entropy and cannot be predicted. This matters for passwords, cryptographic keys, and fair draws.

Worked Example

Range 1–100, quantity 5, unique checked → five distinct integers, e.g. 17, 84, 3, 62, 41.

Range 1–6, quantity 100 → 100 die rolls.

Understanding Your Result

The numbers are comma-separated. Every value in your range has exactly the same probability — we use rejection sampling to avoid modulo bias.

Common Mistakes

  • Requesting more unique numbers than the range allows.
  • Assuming "random" means "evenly spaced" — random values can cluster.
  • Using this for cryptographic keys directly without proper formatting.
