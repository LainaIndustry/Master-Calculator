What Is Base64?

Base64 is a binary-to-text encoding that represents arbitrary bytes using 64 printable ASCII characters (A–Z, a–z, 0–9, +, /, with = for padding). Every 3 bytes become 4 Base64 characters, so the encoded output is about 33% larger than the input.

How to Use This Tool

  1. Paste your text or Base64 string into the input.
  2. Click Encode (text → Base64) or Decode (Base64 → text).
  3. Copy the result with the button.

What Base64 Is Used For

  • Email attachments (MIME): Encodes binary data so it survives text-only email servers.
  • Data URIs: Embed images directly in HTML/CSS as data:image/png;base64,....
  • APIs: JSON often carries binary data as Base64.
  • JWTs: The header and payload of a JSON Web Token are Base64-encoded.

Important: Base64 Is Not Encryption

Base64 provides no security. Anyone can decode it with the same tools. Never use Base64 to "hide" passwords, keys, or sensitive data. Use proper encryption (AES, TLS) instead.

Example

The text Hello encodes to Base64 as SGVsbG8=.

Why the padding? 5 bytes × 8 bits = 40 bits. 40 ÷ 6 = 6.67 → needs 7 Base64 characters, so it's padded with one = to reach 8 characters (2 groups of 4).

Common Mistakes

  • Assuming Base64 is secure — it isn't.
  • Confusing Base64 with Base32, Base58, or URL-safe Base64 (which replaces + and / with - and _).
  • Forgetting that Base64 output is longer than input (about 33% overhead).
