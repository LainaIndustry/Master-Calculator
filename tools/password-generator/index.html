What Is a Password Generator?

A password generator creates random strings of characters that are extremely difficult for attackers to guess. Unlike human-chosen passwords — which tend to follow predictable patterns — generated passwords have maximum entropy.

How to Use This Tool

  1. Choose a length — 16+ characters is recommended.
  2. Select the character sets you want (uppercase, lowercase, digits, symbols).
  3. Click Generate Password.
  4. Click Copy and paste it into your password manager.

How It Works

This tool uses the Web Crypto API's crypto.getRandomValues() — a cryptographically secure pseudorandom number generator. Unlike Math.random(), it produces unpredictable values suitable for security-critical use. We use rejection sampling to eliminate modulo bias, ensuring every character in the selected pool has exactly the same probability.

Password Strength — Entropy

Entropy measures how hard a password is to brute-force, expressed in bits. The formula is:

Entropy (bits) = length × log₂(size of character pool)

Rough guidelines:

EntropyStrengthUse case
< 40 bitsWeakNot recommended
40–59 bitsModerateLow-risk accounts
60–79 bitsStrongMost accounts
80–99 bitsVery strongBanking, email
100+ bitsExcellentPassword manager master

Example

A 16-character password using lowercase + uppercase + digits (pool of 62 characters) gives:

16 × log₂(62) ≈ 16 × 5.95 ≈ 95 bits of entropy — very strong.

Common Mistakes

  • Reusing passwords across sites — one breach compromises all your accounts.
  • Choosing "memorable" patterns like Password123! — trivially cracked.
  • Storing passwords in plain text or in a browser without a master lock.
  • Sharing generated passwords over email or chat.
