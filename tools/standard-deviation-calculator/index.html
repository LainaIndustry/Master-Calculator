What Is Standard Deviation?

It measures how spread out a set of numbers is. A low standard deviation means the values cluster tightly around the mean; a high one means they spread wide.

How to Use It

  1. Paste your data set (comma, space, or line-separated).
  2. Choose sample (n−1) or population (n).
  3. Results appear live.

Formulas

Population standard deviation (σ):

σ = √( Σ(xᵢ − μ)² / N )

Sample standard deviation (s):

s = √( Σ(xᵢ − x̄)² / (N − 1) )

Worked Example

Data: [4, 8, 6, 5, 3]

  • Mean = 26/5 = 5.2
  • Squared deviations: 1.44, 7.84, 0.64, 0.04, 4.84 → sum = 14.80
  • Population variance = 14.80/5 = 2.96 → σ = 1.72
  • Sample variance = 14.80/4 = 3.70 → s = 1.92

Understanding Your Result

For a normal distribution, roughly 68% of values lie within ±1σ of the mean, 95% within ±2σ, and 99.7% within ±3σ.

Common Mistakes

  • Using sample when you have the full population (or vice versa).
  • Forgetting that outliers inflate σ dramatically.
  • Confusing standard deviation with variance (σ² vs σ).
  • Assuming data is normal without checking.
