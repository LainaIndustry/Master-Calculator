What Is a Percentage Calculator?

A percentage calculator converts between ratios, fractions, and the "parts per hundred" notation. This version offers seven distinct modes so any percentage scenario is one click away.

How to Use It

  1. Pick the mode that matches your question.
  2. Enter your numbers.
  3. Results update live.

Percentage Formulas

  • X% of Y: (X ÷ 100) × Y
  • X is what % of Y: (X ÷ Y) × 100
  • % change: ((New − Old) ÷ |Old|) × 100
  • Reverse %: Original = Final ÷ (1 ± Change/100)
  • Compounded: Final = Start × (1 + pct/100)^periods

Common Mistakes

  • Using the new value as the denominator for percent change (always use the old).
  • Confusing percentage points with percent change.
  • Adding stacked percentages rather than multiplying the remaining fractions.
  • Dividing by zero — the calculator will warn you.
