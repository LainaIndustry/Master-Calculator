What Is an Hours Calculator?

It computes the duration between two times, with an optional break deduction. Common uses: timesheet entries, payroll, freelance billing, and shift planning.

How to Use It

  1. Enter the start time and end time.
  2. Enter break minutes (unpaid time).
  3. (Optional) Enter your hourly rate to see estimated pay.
  4. Results appear instantly.

Handling Overnight Shifts

If the end time is earlier than the start time, the calculator assumes the shift crosses midnight. E.g. 22:00 → 06:00 = 8 hours.

Example

9:00 AM to 5:30 PM with a 30-minute break: 8.5 hours − 0.5 break = 8.0 hours. At $20/hour: $160.

Common Mistakes

  • Forgetting to deduct unpaid breaks.
  • Confusing AM/PM and creating a 12-hour error.
  • Using decimal hours in timesheets when employers expect HH:MM (or vice versa). 8:15 = 8.25 hours.
  • Forgetting overtime rules — many jurisdictions require 1.5× pay after 40 hours/week.
